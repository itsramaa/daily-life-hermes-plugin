# Daily Life Hermes Plugin

Master daily orchestrator for Hermes agent: interoception, resilient briefing, adaptive planning, connecting dot adapters, and learning optimization.

## Features

- **Daily Cycle**: Periodic status check, circadian tracking, and briefing generation.
- **Adaptive Planning**: Task replanning and outcome tracking.
- **Multi-Profile Support**: Profile-aware database resolution and adapter configuration.
- **Adapters**: Integrations for Calendar, Gmail, Tebar, and internal Hermes toolsets.
- **Dashboard & Commands**: Built-in dashboard views and CLI commands (`/daily`).
